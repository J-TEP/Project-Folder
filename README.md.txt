# Cybersecurity Portfolio & Technical Labs

Welcome to my cybersecurity repository. This space highlights hands-on technical labs, security assessments, and protocol analysis demonstrating practical skills in defensive and offensive security concepts.

## Repository Structure

* **[PortSwigger Labs](./portswigger/)** — Documentation and request/response walkthroughs from the PortSwigger Web Security Academy, focusing on web application vulnerabilities like SQL injection and API endpoint exploitation using Burp Suite.
* **[PCAP Analysis](./pcap-analysis/)** — *Coming Soon:* Upcoming network traffic capture investigations utilizing tools like Wireshark and tcpdump to analyze packet anomalies and protocol behavior.
